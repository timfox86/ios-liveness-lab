Getting started on iPhone

Host this HTML file on an HTTPS website you control (for example, GitHub Pages), then open that HTTPS URL in Safari. Tap Start live camera and allow camera access. For synthetic testing, tap Choose synthetic video and select a video in Files or Photos if available in the picker.

A file:// page or an ordinary http:// site may not have working camera permissions. For initial testing on a computer, localhost is a secure context in most modern browsers. No network request is made by the page itself.
